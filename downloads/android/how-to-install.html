Streets of Roanoke 2.1.1

Install on Android

The app is one file, Streets-of-Roanoke-2.1.1-debug.apk, about 453 MB. That is over GitHub's 100 MB limit, so it ships as twenty parts. Each part is a .zip that holds one 7z volume. Download all twenty, keep the names exactly as they are, and leave them in the same folder. Unzip each .zip, then unpack volume .001. The unpacker reads .002 through .020 by itself.

"App not installed"

Android got as far as the .apk and then stopped with App not installed.

  • An older Streets of Roanoke or Star City Drift app is already installed, and it was signed differently, so Android will not replace it. Uninstall the old copy first: Settings → Apps → Streets of Roanoke (or Star City Drift) → Uninstall. Then tap Streets-of-Roanoke-2.1.1-debug.apk again. Uninstalling removes that old app's saved data, so only do this when install-over fails.
  • Free about 500 MB of storage. The download is about 453 MB, and Android needs extra room to unpack the app. Check Settings → Storage, remove files you do not need, and tap Install again.
  • You have to install Streets-of-Roanoke-2.1.1-debug.apk. Tapping a .7z.001 file will not install the game.

Play Protect warning

Google Play Protect may warn you, or say the app was blocked, because this app did not come from the Play Store. Tap More details, then Install anyway. This is the Streets of Roanoke 2.1.1 build published with the game.

Saves and later updates

When this version installs over an older Streets of Roanoke app, your old saves carry over. You do not start the story again.

After the app is on the phone, later game updates install themselves when you are online. You do not download the twenty parts again for a normal update.
