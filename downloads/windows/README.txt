EASIEST: 7-Zip (free, https://www.7-zip.org)
  1. Install 7-Zip.
  2. Right-click Star-City-Drift-1.1.0-win-x64.7z.001 > 7-Zip > Extract Here
     (or open the .001 in 7-Zip). It reads .002-.004 by itself.
  3. Open the new "Star City Drift" folder and double-click "Star City Drift.exe".
  NanaZip, PeaZip and WinRAR open the .001 the same way.

WITHOUT 7-ZIP (Windows 11 only)
  Windows can't open the .001 file directly. Join the parts into one .7z first:
  in that folder, click the address bar, type  cmd  and press Enter, then run:
    copy /b Star-City-Drift-1.1.0-win-x64.7z.001+Star-City-Drift-1.1.0-win-x64.7z.002+Star-City-Drift-1.1.0-win-x64.7z.003+Star-City-Drift-1.1.0-win-x64.7z.004 Star-City-Drift-1.1.0-win-x64.7z
  Then right-click Star-City-Drift-1.1.0-win-x64.7z > Extract All. Windows 11 has opened .7z files
  natively since the 23H2 update. Windows 10 can't open .7z, so use 7-Zip there.

FIRST RUN
  The app isn't code-signed, so SmartScreen may say "Windows protected your PC".
  Click "More info" > "Run anyway".
  F11 or Alt+Enter toggles fullscreen. Esc pauses. Saves are kept in %APPDATA%\Star City Drift.
  This is the portable app (nothing gets installed). Keep the whole folder together. You can move it
  anywhere, e.g. Desktop or Documents, and make a shortcut to "Star City Drift.exe".
  To uninstall, delete the folder.
  (To keep the download small, only the English Chromium language pack is included. The game is
  English anyway.)
