Star City Drift 1.1.0 — Windows x64

This build is split into five parts. Download all of them into the same folder and do not rename them:

  Star-City-Drift-1.1.0-win-x64.7z.001
  Star-City-Drift-1.1.0-win-x64.7z.002
  Star-City-Drift-1.1.0-win-x64.7z.003
  Star-City-Drift-1.1.0-win-x64.7z.004
  Star-City-Drift-1.1.0-win-x64.7z.005

Install 7-Zip (https://www.7-zip.org/) if you do not already have it.

Right-click Star-City-Drift-1.1.0-win-x64.7z.001 and choose 7-Zip → Extract Here.
7-Zip uses the other parts automatically.

Run the extracted Star City Drift program.
