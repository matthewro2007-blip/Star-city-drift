STREETS OF ROANOKE 1.7.0 ON A CHROMEBOOK
(formerly Star City Drift)
======================================

There are three ways to play on a Chromebook. Option A is the easiest and works on
every Chromebook.

OPTION A (EASIEST, RECOMMENDED): INSTALL THE WEB APP FROM CHROME
  1. Open Chrome and go to  https://matthewro2007-blip.github.io/Star-city-drift/
  2. Click the Install icon at the right end of the address bar (a screen with a down
     arrow), or open the three-dot menu > Cast, save, and share > Install page as app.
  3. Click Install. Streets of Roanoke appears in your Launcher like any other app.
  It works offline after the first load, updates itself when you're online, and keeps
  your saves. Nothing else to download. Works on Intel, AMD and ARM Chromebooks.
  (Already installed it as Star City Drift? It updates itself to the new name.)

OPTION B: THE ANDROID APK
  Only for Chromebooks with Google Play / Android apps turned on
  (Settings > Apps > Google Play Store).
  ChromeOS only installs Play Store apps by default. Installing a downloaded .apk
  (sideloading) needs ChromeOS developer mode, which wipes the Chromebook and turns off
  some security. School and work Chromebooks usually block it. We don't recommend it:
  use Option A or Option C instead.

OPTION C: THE LINUX APP (.deb) - INTEL/AMD CHROMEBOOKS
  This is the full desktop app. It needs a Chromebook with an Intel or AMD processor
  (ARM Chromebooks: use Option A). School and work Chromebooks may not allow Linux.
  1. Turn on Linux: Settings > Advanced > Developers > Linux development environment >
     Turn on, and follow the steps. (On some versions: Settings > About ChromeOS >
     Developers.) This does NOT need developer mode.
  2. Download all 7 parts into the same folder:
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.001   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.002   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.003   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.004   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.005   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.006   (23.1 MB)
       Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.007   (12.6 MB)
     Together they're one 7-Zip archive holding Streets-of-Roanoke-1.7.0-chromebook-amd64.deb.
  3. In the Files app, move all the parts into "Linux files".
  4. Open the Terminal app (Launcher > Linux apps > Terminal) and run these two lines:
       sudo apt install -y p7zip-full
       7z x Streets-of-Roanoke-1.7.0-chromebook-linux-x64.7z.001
     This makes Streets-of-Roanoke-1.7.0-chromebook-amd64.deb in Linux files.
     (You can delete the .7z parts afterwards.)
  5. In the Files app, double-click Streets-of-Roanoke-1.7.0-chromebook-amd64.deb, then click
     Install. Wait for the "Installation complete" notice.
  6. Open Streets of Roanoke from Launcher > Linux apps.
  Or install from the Terminal instead of step 5:
       sudo apt install -y ./Streets-of-Roanoke-1.7.0-chromebook-amd64.deb
  Already have Star City Drift 1.6.0 from the .deb? Install this over it: it is the same
  package (star-city-drift), it replaces the old one and keeps your saves.
  It plays the copy that came with it offline, and updates itself from the website when
  you're online, so you don't need to reinstall for new versions. F11 toggles fullscreen.
  To uninstall: right-click it in Launcher > Uninstall, or  sudo apt remove star-city-drift

WHICH ONE?
  Most people: Option A. Want the desktop app on an Intel/AMD Chromebook: Option C.
