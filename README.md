# Streets of Roanoke

Streets of Roanoke (formerly Star City Drift) is a finished 2D arcade beat 'em up set in Roanoke, Virginia, the Star City. You play as Matthew Rose, free-roaming the streets, clearing thug waves, and finishing the job. It is a static site of vanilla ES modules and canvas (no build step) and can be installed as an app on PC and phone.

Version 1.5.0 adds a free prequel DLC where you play as Silas Boone. Version 1.6.0 rewrites the story as "The Star Goes Dark" and adds the Dark Star Suit. Version 1.7.0, "Locked Up", added the arrest ending, the Cinder Hollow prison to explore after the story, the Cinder Hollow Orange outfit, New Game+, a Sunny / Night / Rainy weather switch, and the new name. Version 1.8.0 is the HD Remaster: every character and background redrawn at twice the detail, drawn at 1920x1080 on big screens.

Play it at https://matthewro2007-blip.github.io/Star-city-drift/

## Install as an app

- **Chrome or Edge on PC:** use the install icon in the address bar.
- **Android Chrome:** Add to Home screen, or Install app.
- **iPhone Safari:** Share, then Add to Home Screen.

## iPhone

The easiest way is Safari: open the game, tap **Share**, then **Add to Home Screen**. It runs full screen, works offline and updates itself. Full steps are in [IPHONE.txt](downloads/iphone/IPHONE.txt).

There is also an unsigned iPhone app, [Streets-of-Roanoke-1.8.0.ipa](https://github.com/matthewro2007-blip/Star-city-drift/releases/download/ios-v1.8.0/Streets-of-Roanoke-1.8.0.ipa), built by GitHub Actions and published on the `ios-v1.8.0` Release (about 150 MB, over GitHub's 100 MB file limit). It isn't on the App Store. You sign it yourself with your own Apple ID using [AltStore](https://altstore.io) or [Sideloadly](https://sideloadly.io). With a free Apple ID it has to be re-signed every 7 days. A paid Apple developer account makes it last a year and allows TestFlight.

## Controls

- **Keyboard:** WASD or arrows move, Z punch, X kick, C heavy, E talk, T weather (Sunny / Night / Rainy), 1–5 outfits, Esc pause/save. Weather is also on the title screen and in the pause menu, and it is remembered on this device.
- **Controllers:** PlayStation 5 and Xbox controllers are supported. Create / View cycles the weather.
- **Phones:** on-screen touch controls, plus a weather button.
